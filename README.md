# 🎬 Alien, el Octavo Pasajero — Sitio Web Multipágina

Sitio web multipágina dedicado a la película **Alien, el Octavo Pasajero (1979)**, desarrollado desde cero como proyecto final de la cursada de Desarrollo Web. El enfoque principal fue la **maquetación web tradicional y avanzada sin frameworks**, aplicando CSS nativo modular, estructuración semántica rigurosa en HTML5, diseño responsive y una arquitectura limpia de archivos.

---

## 🚀 Tecnologías Utilizadas
* **HTML5:** Estructuración semántica avanzada para múltiples vistas conectadas.
* **CSS3 (Nativo):** Estilos personalizados, diseño modular con hojas de estilo independientes por sección, manejo de tipografías locales y maquetación estructurada sin librerías externas.
* **Diseño Responsive:** Adaptación a escritorio, tablet y celular mediante *media queries*, con menú hamburguesa por debajo de los 850 px.

---

## 📋 Estructura y Características del Sitio
* **Navegación Multipágina:** Integración fluida entre las distintas secciones temáticas:
  * 🏠 **Inicio (`index.html`)** — Portada de presentación de la película.
  * ℹ️ **Sobre la película (`about.html`)** — Datos técnicos, sinopsis y análisis del impacto de la obra.
  * 🎭 **Reparto (`reparto.html`)** — Perfiles del elenco principal (Sigourney Weaver, Tom Skerritt, John Hurt, entre otros).
  * 🎬 **Producción (`produccion.html`)** — Detalles del rodaje, producción y distribución.
  * 🧪 **Curiosidades y Premios (`curiosidades.html`)** — Datos poco conocidos, premios, nominaciones e impacto cultural.
  * ✉️ **Contacto (`contacto.html`)** — Formulario de consulta con página de confirmación (`confirmacion.html`).
* **Páginas de Sistema y Extras:**
  * ⚠️ Página de error personalizada (`404.html`).
  * 🕵️‍♂️ *Easter egg* oculto dentro de la experiencia del sitio (`easteregg.html`).
* **Diseño Modular:** Cada sección cuenta con sus propias hojas de estilo independientes (`estilos/`), garantizando un mantenimiento del código limpio y organizado.
* **Accesibilidad:** Marcado semántico, atributo `lang` declarado y texto alternativo en la totalidad de las imágenes del sitio.
