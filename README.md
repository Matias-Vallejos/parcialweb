# 🌐 Sitio Web Multisección (Parcial de Desarrollo Web)

Sitio web multipágina completo desarrollado desde cero como proyecto evaluativo (Parcial) para la cursada de Desarrollo Web. El enfoque principal del proyecto fue la **maquetación web tradicional y avanzada sin frameworks**, aplicando CSS nativo modular, estructuración semántica rigurosa en HTML5 y una arquitectura limpia de archivos.

---

## 🚀 Tecnologías Utilizadas
* **HTML5:** Estructuración semántica avanzada para múltiples vistas conectadas.
* **CSS3 (Nativo):** Estilos personalizados, diseño modular con hojas de estilo independientes por sección, manejo de tipografías locales y maquetación estructurada sin librerías externas.

---

## 📋 Estructura y Características del Sitio
* **Navegación Multipágina:** Integración fluida entre diferentes secciones temáticas:
  * 🏠 **Inicio (`index.html`)**
  * ℹ️ **Sobre Nosotros (`about.html`)**
  * 🎬 **Producción (`produccion.html`)**
  * 🧪 **Curiosidades (`curiosidades.html`)**
  * ✉️ **Contacto (`contacto.html`)**
* **Páginas de Sistema y Extras:** 
  * ⚠️ Página de error personalizada (`404.html`).
  * 🕵️‍♂️ Sección secreta / *Easter Egg* oculta dentro de la experiencia del sitio.
* **Diseño Modular:** Cada sección cuenta con sus propias hojas de estilo independientes (`estilos/`), garantizando un mantenimiento del código limpio y organizado.
